## RAWR
Hi Dino here, 
Ever accidentally build things that should not exist? \
You start simply start a project thinking I will hit a wall and give up, I will be free then!! \
And then the walls just keep crumbling... and suddenly you build a declarative TUI framework in nothing but bash. 
And then it is not even that bad... 

## Projects

### DABT and terminal tools

- [DinosAmazingBashTui (DABT)](https://github.com/DinosaursAreCute/DinosAmazingBashTui): a pure-Bash framework for building terminal UIs with XML pages, CSS-like themes, mouse support, and live process panes.
- [DinosAmazingDabtPlugin](https://github.com/DinosaursAreCute/DinosAmazingDabtPlugin): VS Code tooling for DABT apps, including linting, completion, debugging, and profiling.
- [DabtFileExplorer](https://github.com/DinosaursAreCute/DabtFileExplorer): a keyboard- and mouse-driven terminal file explorer built with DABT.
- [dabt_profiler-studio](https://github.com/DinosaursAreCute/dabt_profiler-studio): a desktop app for running and exploring DABT profiler results.
- [bash_visualizer](https://github.com/DinosaursAreCute/bash_visualizer): a desktop app to run, trace, and inspect Bash scripts.
- [DabTop](https://github.com/DinosaursAreCute/DabTop): a btop-inspired system monitor for DABT.

### Other applications and utilities
- [wsl_ctl](https://github.com/DinosaursAreCute/wsl_ctl) — a terminal menu for managing WSL distributions.
- [vm_scripts](https://github.com/DinosaursAreCute/vm_scripts) — scripts for starting VirtualBox VMs and opening an SSH connection.
- [Dinos_Windows_Themes](https://github.com/DinosaursAreCute/Dinos_Windows_Themes) — a Windows customization pack with themes, settings, and helper scripts.
- [Dinos_Better_Desktop_Controls](https://github.com/DinosaursAreCute/Dinos_Better_Desktop_Controls) — AutoHotkey shortcuts for switching Windows virtual desktops.
